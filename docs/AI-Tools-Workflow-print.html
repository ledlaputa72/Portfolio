2. AI 도구별 역할

2.1 Claude Code (웹/클라우드) — 주 담당

GitHub 연결 클라우드 코딩. 멀티파일 구현, 기획, 콘텐츠, 배포.

역할작업
전략·기획IA, 컴포넌트 설계, Phase 우선순위
텍스트Hero 카피, About, 케이스 스터디 교정
멀티파일 구현페이지·라우트·섹션 대량 생성
배포Vercel, 도메인, CI/CD

세션 시작: GitHub pull + 기획서 + 본 문서 참조 후 [작업] 진행

2.2 Cursor (로컬 IDE) — 주 담당

D:\New Steve\AI Portfolio. 로컬 dev server, UI 미세 조정, 3D/애니메이션 디버깅.

역할작업
로컬 검증npm run dev, localhost:3000
UI 미세 조정간격, 색, 타이밍, 반응형
3D·인터랙션R3F, GSAP, Lenis
버그·품질빌드, lint, Lighthouse, 모바일

2.3 Claude (대화) — 주 담당

기획 논의, 텍스트 작성, Artifacts 프로토타입, 문서 작성. Repo 직접 수정은 Claude Code/Cursor 담당.

2.4 Gemini — 보조

Google Drive 연동, 이미지 분석, 스크린샷→카피. 코드·Git은 Claude Code/Cursor.

2.5 사용하지 않는 도구

v0, Framer, Webflow — Next.js 직접 코딩으로 확정.

4. 권장 워크플로

패턴 A — Claude Code 선행

  1. Claude Code: 구조·페이지 구현 → push
  2. Cursor: pull → 로컬 확인·UI 다듬기 → push
  3. Claude Code: pull → 다음 페이지 이어서

패턴 B — Cursor 선행

  1. Cursor: Hero/3D/반응형 수정 → push
  2. Claude Code: pull → About 등 이어서

패턴 C — 병렬

Claude Code: 텍스트·Contact · Cursor: Gallery·3D. 같은 파일 동시 수정 금지.
